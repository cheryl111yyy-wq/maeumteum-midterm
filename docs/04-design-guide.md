# 디자인 가이드

## 시각 방향

간결하고 부드러우며 차분한 인상을 목표로 합니다. 화면은 빠른 기록과 회고를 돕고, 연속 기록을 강요하는 게임형 표현이나 색상만으로 상태를 전달하는 방식을 사용하지 않습니다.

## 색상

| 용도 | 값 | 사용 위치 |
|---|---|---|
| 화면 배경 | `#F8F7F3` | Scaffold 배경 |
| 기본 글자 | `#292A2D` | 제목, 버튼, 본문 |
| 보조 글자 | `#85858B` | 안내, 날짜, 보조 정보 |
| 포인트 색 | `#A79BC8` | 선택 테두리, 강조 배경 |
| 보조 색 | `#A8B8A0` | 완료 상태, 태그 배경 |
| 카드 | `#FFFFFF` | 기록, 달력, 리포트 |
| 테두리 | `#E8E5DE` | 카드, 입력창, 구분선 |
| 알림 색 | `#E7B99D` | 검증, 오류 표시 |

## 타이포그래피

Flutter 프로토타입은 시스템 글꼴을 사용해 한국어와 기기 환경에서 안정적으로 표시합니다.

| 계층 | 크기 | 굵기 |
|---|---|---|
| 화면 주제목 | 26–32px | 700 |
| 영역 제목 | 17–21px | 700 |
| 본문 | 14–16px | 400–600 |
| 보조 문구 | 12–13px | 400–500 |

정식 브랜드 버전에서 Pretendard를 사용할 경우 글꼴 라이선스를 확인하고 `pubspec.yaml`에 등록해야 합니다.

## 간격

- 화면 좌우 여백: 22px
- 주요 영역 사이: 22–28px
- 카드 안쪽 여백: 18–22px
- 컨트롤 사이: 8–12px
- 주요 버튼 높이: 52px
- 카드 모서리: 18px
- 작은 컨트롤 모서리: 12–16px

## 카드와 버튼

- 카드는 테두리와 여백으로 계층을 만들고 강한 그림자는 사용하지 않습니다.
- 주요 버튼은 현재 화면에서 가장 중요한 행동 하나에 사용합니다.
- 아이콘 버튼에는 `tooltip` 또는 의미 있는 접근성 라벨을 제공합니다.
- 선택 상태는 테두리, 배경, 체크, 글자 굵기를 함께 사용합니다.

## 아이콘

Material 아이콘을 사용하며 선형 아이콘을 기본으로 합니다.

- 기록: `edit_note_outlined`
- 수업: `school_outlined`
- 과제: `assignment_outlined`
- 시험: `quiz_outlined`
- 아르바이트: `work_outline`
- 친구: `people_outline`
- 휴식: `self_improvement_outlined`
- 수면: `bedtime_outlined`

## 상태 피드백

| 상태 | 시각 요소 | 문구 |
|---|---|---|
| Loading | 진행 표시 | 마음을 불러오고 있어요 |
| Error | 서버 연결 끊김 아이콘 + 재시도 | 데이터를 불러오지 못했어요 |
| Empty | 빈 기록함 아이콘 | 아직 표시할 기록이 없어요 |
| Selected | 테두리와 체크 | 선택한 항목을 컨트롤 자체에서 표시 |
| Completed | 체크 아이콘 + 오늘 요약 | 오늘의 기록 |

## 문장 원칙

- 감정의 좋고 나쁨을 평가하지 않습니다.
- `매일 반드시 기록해야 한다`와 같은 압박 문구를 사용하지 않습니다.
- 주간 리포트는 기록을 설명하고 심리 원인을 추론하지 않습니다.
- `필수`와 `선택`을 해당 영역 제목 옆에 직접 표시합니다.
- 저장 범위를 명확히 설명하고 메모리 상태를 영구 저장처럼 표현하지 않습니다.

## 접근성

- 감정 선택 항목에는 명확한 의미 라벨을 제공합니다.
- 태그 선택에는 `FilterChip`을 사용해 조작 의미를 제공합니다.
- 글자와 배경의 대비를 충분히 확보합니다.
- 오류 화면에는 `다시 시도` 행동을 제공합니다.
- 좁은 화면에서는 스크롤을 허용하고 본문을 고정 높이로 자르지 않습니다.
