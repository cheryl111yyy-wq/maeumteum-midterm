# 디자인 가이드

## 视觉方向

简约、柔和、成熟、有编辑感。界面服务于快速记录与回顾，不使用惩罚式连续打卡，不用颜色单独表达状态。

## 색상

| 用途 | 값 | 使用位置 |
|---|---|---|
| 页面背景 | `#F8F7F3` | Scaffold 背景 |
| 主文字 | `#292A2D` | 标题、按钮、正文 |
| 次要文字 | `#85858B` | 说明、日期、辅助信息 |
| 主色 | `#A79BC8` | 选中边框、重点背景 |
| 辅助色 | `#A8B8A0` | 完成状态、标签浅背景 |
| 卡片 | `#FFFFFF` | 记录、日历、报告 |
| 边框 | `#E8E5DE` | 卡片、输入框、分隔线 |
| 提醒色 | `#E7B99D` | 校验和错误图形 |

## 타이포그래피

Flutter 原型使用系统字体，确保韩文与设备环境稳定。字号层级：

| 层级 | 字号 | 字重 |
|---|---|---|
| 页面主标题 | 26–32 px | 700 |
| 区块标题 | 17–21 px | 700 |
| 正文 | 14–16 px | 400–600 |
| 辅助文字 | 12–13 px | 400–500 |

正式品牌版本可改用 Pretendard，但必须先确认字体文件授权并加入 `pubspec.yaml`。

## 간격

- 页面左右：22 px。
- 区块之间：22–28 px。
- 卡片内边距：18–22 px。
- 控件之间：8–12 px。
- 主按钮高度：52 px。
- 卡片圆角：18 px。
- 小控件圆角：12–16 px。

## 카드와 버튼

- 卡片主要依靠边框与留白建立层级，不使用厚重阴影。
- 主按钮只用于当前页面最重要的操作。
- 图标按钮必须带 `tooltip` 或语义标签。
- 选中状态同时使用边框、背景、勾选与文字字重，不只依赖颜色。

## 아이콘

使用 Material 图标，保持线性图标为主：

- 기록：`edit_note_outlined`
- 수업：`school_outlined`
- 과제：`assignment_outlined`
- 시험：`quiz_outlined`
- 아르바이트：`work_outline`
- 친구：`people_outline`
- 휴식：`self_improvement_outlined`
- 수면：`bedtime_outlined`

## 상태 피드백

| 상태 | 视觉 | 文案 |
|---|---|---|
| Loading | 进度圈 | 마음을 불러오고 있어요 |
| Error | 云断开图标 + 重试 | 데이터를 불러오지 못했어요 |
| Empty | 空箱图标 | 아직 표시할 기록이 없어요 |
| Selected | 边框与勾选 | 由控件自身表达 |
| Completed | 勾选图标 + 今日摘要 | 오늘의 기록 |

## 문장 원칙

- 不评价情绪好坏。
- 不使用“必须每天记录”等压迫性文案。
- 周报只描述记录，不推断心理原因。
- “선택”与“필수”直接放在对应区块标题旁。
- 对原型限制使用明确说明，不把内存状态描述成永久保存。

## 접근성

- 每个可点击心情项带明确语义标签。
- 标签选择使用 `FilterChip`，自带可操作语义。
- 文字与背景保持足够对比。
- 错误状态提供可操作的“다시 시도”。
- 窄屏允许滚动，不固定高度裁切正文。
