# 자기평가

## 완료한 것

- 四个核心页面可操作。
- 初次 GET 使用 `FutureBuilder<AppData>` 处理 waiting、error、empty、success。
- 心情、标签与备注的选中状态使用 `setState()` 更新。
- 新记录会更新本次运行中的今日摘要、日历和最近 7 天报告。
- 首页进入记录页使用 `Navigator.push`。
- 历史日期详情使用 `showModalBottomSheet`。
- 正常、加载、空、错误状态均可触发。
- GET 请求从本地 `json-server` 读取。
- 手机与宽屏布局均有响应式分支。
- Flutter 静态分析与组件测试通过。
- Flutter Web release build 通过。

## 尚未完成或有限制

- 新记录不写入服务器或本地数据库，关闭后消失。
- 心情与生活标签使用固定初始分类，没有用户测试验证。
- 周报基于示例数据和本次运行记录计算，不代表真实用户样本。
- 尚未完成正式用户访谈和可用性测试。
- DailyBean 的 Google Play 评分分布与三条评论已记录；正式页面截图仍建议归档。
- 情绪选择阶段的犹豫是设计假设，不能写成 DailyBean 评论已经证实的事实。
- 还没有部署 URL，最终建议录制 1 分钟演示视频。

## 设计决策的变化

1. 备注从“视觉上与必填项相同”改为明确“선택”。
2. 首页从“承载全部功能”改为“快速选择 + 今日摘要”。
3. 首页只保留常用标签，全部标签移动到记录页。
4. 放弃 App 内 AI 心理分析，把 AI 用于设计反方与文档审查。
5. 第 8 页改用真实 Flutter Before/After 截图，Before 明确标记为 폐기안。
