# DailyBean 경쟁 앱 분석

## 분석 목적

DailyBean은 감정, 일상 활동, 기록 회고를 중심으로 한다는 점에서 마음틈과 비교하기 적합합니다. 이 분석의 목적은 DailyBean의 장점을 참고하고, 대학생 사용자가 부담 없이 기록을 시작할 수 있는 개선 기회를 찾는 것입니다. DailyBean을 기능이 부족한 앱으로 평가하지 않습니다.

## 확인한 제품 정보

- 감정, 활동, 글, 사진, 사용자 분류, 아이콘, 테마, 달력, 리포트, 잠금 기능
- 아이콘을 눌러 긴 일기보다 짧게 기록할 수 있는 흐름
- 일부 고급 테마, 분석, 사진, 광고 제거 기능은 유료 범위

## 실제 리뷰 근거

R1은 사용자가 제공한 3점 리뷰 캡처를 번역한 것이고 날짜는 2024-06-04입니다. R2와 R3는 2026-10-28에 확인한 Google Play 공개 리뷰입니다.

| 번호 | 출처 | 날짜 | 별점 | 유형 | 리뷰 요지 | 디자인 문제 | 마음틈에 적용한 점 |
|---|---|---|---|---|---|---|---|
| R1 | 사용자 제공 리뷰 캡처 | 2024-06-04 | ★3 | 접속 안정성과 입력 부담 | 앱이 자주 열리지 않고, 감정 하나를 기록하려 해도 선택할 정보가 너무 많음 | 기록 시작 실패와 과도한 입력량이 함께 발생 | 감정 1개만 필수, 태그와 메모는 선택, Loading·Error·Retry 제공 |
| R2 | Google Play | 2025-09-09 | ★4 | 보상과 광고 | 앱의 가치는 인정하지만 보상 확률이 불투명하고 시간이 오래 걸림 | 보상 결과를 예측하기 어려움 | 광고와 무작위 보상 제외 |

## 네 가지 경험 유형

세 리뷰가 반드시 세 가지 유형에만 연결되는 것은 아닙니다. 한 리뷰가 여러 문제를 동시에 말할 수 있으므로 리뷰 문장과 경험 유형을 다중으로 연결했습니다.

| 경험 유형 | 근거 리뷰 | 해석 경계 |
|---|---|---|
| 기록 입력 부담 | R1 | 한 사용자의 실제 경험이며 전체 사용자의 공통 문제로 확대하지 않음 |
| 접속 안정성 | R1 | 한 리뷰가 앱 접속 실패를 직접 언급 |
| 보상 투명성 | R2·R3 | 보상 확률이나 결과가 불투명하다는 의견 |
| 개인화 가치 | R3 | 테마 사용자화에 대한 긍정적 의견 |

## 해석의 경계

- R1은 한 사용자가 접속 실패와 과도한 입력량을 보고한 사례입니다. 전체 사용자에게 같은 문제가 얼마나 퍼져 있는지는 아직 검증하지 않았습니다.
- 감정 선택 단계의 망설임은 R1의 입력 부담 단서와 Persona, Journey, P05, P06을 결합한 설계 가설입니다.
- 대학 생활 태그를 강조한 것은 이 프로젝트의 초점이며 DailyBean에 활동 분류가 없다는 뜻이 아닙니다.
- 간결한 리포트는 정보 구성 제안이며 DailyBean에 리포트가 없다는 뜻이 아닙니다.
- 이 프로토타입은 심리 상태를 진단하거나 감정과 태그의 인과관계를 주장하지 않습니다.
